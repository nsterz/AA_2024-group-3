# AA-2024-Group-3

This is the repository of **Group 3 (Analytics Associates)** for the AA Group Project in the course **Analytics and Application** during the winter term of 2024/25.

## Project Objectives

This project is designed to apply data analytics and machine learning approaches to a real-world problem involving electric vehicle (EV) charging hubs. The key objectives are:

1. **Understanding System Metrics**:
   - Gaining a deep understanding of key metrics related to the operation of EV charging hubs.
   - Presenting these metrics in a user-friendly format for the hub operator’s management.

2. **Prediction of Utilization**:
   - Developing accurate predictive models to forecast future utilization.
   - Enabling better operational planning and facilitating new business models.

By addressing these objectives, the project illustrates how data can be used to solve societal issues and drive business improvements simultaneously.

## Prerequisites

- Ensure you have **Python 3.8 or higher** installed.
- A package manager such as `pip` is required to install dependencies.
- Install **Jupyter Notebook** to run `.ipynb` files.

## Installation

1. Clone this repository to your local machine:
   ```bash
   git clone https://github.com/username/aa-2024-group-3.git
   cd aa-2024-group-3
   ```

2. Install the required Python libraries listed in `requirements.txt`:
   ```bash
   pip install -r requirements.txt
   ```
   Alternatively, you can manually install the libraries specified in `requirements.txt` or in each notebook.

3. Verify the installation by launching a Jupyter Notebook:
   ```bash
   jupyter notebook
   ```

## Deliverables

The project includes the following deliverables:

1. **Data Collection and Preparation**: Ingest, clean, and preprocess the dataset for analysis.
2. **Descriptive Analytics**:
   - Identify temporal patterns and seasonality.
   - Define and visualize key performance indicators (KPIs).
   - Determine site characteristics to identify which site is public and which is private.
3. **Cluster Analysis**: Group charging sessions into archetypes to better understand user behavior.
4. **Utilization Prediction**:
   - Develop predictive models (e.g., neural networks and traditional statistical methods).
   - Compare model performance and propose business cases based on predictions.

Refer to the course materials and syllabus for detailed submission guidelines.
